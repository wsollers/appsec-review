# SEI CERT rule pack

Portable Semgrep CE / OpenGrep rules mapped to SEI CERT C, C++, and Oracle Java rules, with a status
for every inventoried CERT rule (including the draft Android standard). `COVERAGE.md` is the
generated coverage view; `mappings/` is authoritative for status.

- Overview and official-standard links: [`../../docs/SEI-CERT.md`](../../docs/SEI-CERT.md)
- Design, statuses, conventions, and engine portability findings:
  [`../../docs/architecture/sei-cert-rule-pack.md`](../../docs/architecture/sei-cert-rule-pack.md)
- Commands, adding rules, testing both engines, refreshing the source:
  [`../../docs/operations/sei-cert-rule-pack.md`](../../docs/operations/sei-cert-rule-pack.md)

Findings are rule-pack observations. Neither findings nor their absence establish CERT conformance.
