### code_file_outline (tree-sitter)

When: see a file's functions (with real spans), imports and call sites before reading it, so you
read the right range.
Source: the accepted `02-treesitter-ast` summary in the code index. Files without a grammar,
oversized or unreadable files are gaps (`file-not-in-index`).
Cite: read the lines; the outline itself is a locator.
