# Deterministic DFD and STRIDE core

Consume only the current accepted F03 component map and the exact F02 assembly it binds. Produce
the canonical integrated threat-model JSON with deterministic elements, flows, trust boundaries,
candidate STRIDE hypotheses, assumptions, coverage, gaps, and bounded rescope triggers. Every
record must cite both the accepted component map and a dereferenced hash-verified F02 artifact.

Candidate hypotheses are routing inputs for downstream verification. They are not findings,
verified facts, runtime observations, severity judgments, compliance verdicts, or remediation.
