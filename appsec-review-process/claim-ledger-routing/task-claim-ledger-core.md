# Claim-ledger core task

Consume only exact accepted candidate-route artifacts. Preserve their hashes, producer attempts,
source/component generations, citations, proof obligations and dissent. Append deterministic entries
to one validated hash chain. Reject mixed generations, duplicate identities, broken chains, cycles,
self-verification and unauthorized status transitions. Admission is candidate-only and cannot create
a finding, severity, runtime, compliance or remediation claim. Later-stage routes remain inert.
