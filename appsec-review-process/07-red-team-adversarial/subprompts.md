# Subprompts — Red Team / Adversarial

## Known Issue Matrix

For each component or parallel review group in the component-purpose map, select applicable issue
classes from `known-issue-catalog.md`. For each selected issue class, write one evidence-backed
hypothesis or explicitly mark it as not applicable with negative evidence.

Do not turn catalog entries into findings without target-specific evidence.

## Exploitability Argument

Build the strongest evidence-backed exploitability argument for one unresolved or deep-confirmed
cluster.

## Hostile Vendor Placement

Identify where malicious or trust-breaking code would be easiest to hide given current coverage gaps.

## Goal-Conformance Challenge

Ask whether the current process actually answers the user's stated accept/ship/integrate decision.
