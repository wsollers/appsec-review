# Subprompts — ASVS / MASVS

## ASVS Mapping

Map each component to ASVS chapters and produce the inverse chapter-to-component worklist.

## ASVS Chapter Assessment

Assess one ASVS chapter against one component group. Stay within the chapter. Cite exact
requirements, evidence, and gaps.

## MASVS Mobile Assessment

Assess mobile client components against MASVS/MASTG. Include permissions, data storage, network,
platform interaction, code quality, resilience, and privacy-relevant SDK/data flows.
