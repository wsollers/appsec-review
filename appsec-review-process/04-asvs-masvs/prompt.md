# Prompt — ASVS / MASVS Applicability And Assessment

Map components to applicable ASVS/MASVS controls using evidence. Do not run the whole checklist
against every component.

For each component:

- identify applicable standards chapters
- explain why they apply
- identify not-applicable controls with evidence
- mark unknowns that require manual or dynamic verification
- produce a worklist for targeted control assessment

For each assessed control, cite exact code/config/tool evidence. Absence of a finding is not evidence
of a control.
