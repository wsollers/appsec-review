# Brief E: language-aware dependency reachability (branch `dep-reachability`)

Goal: for each dependency vulnerability (SCA/OSV match), decide whether application code can reach the vulnerable code: output `reachable | unreachable | unknown` with a witness path, and feed the existing rule "Critical requires REACHABLE". Wire `06-cve-reachability` into `full_review` (today `reachability.py cve-evidence` is an offline command needing a reviewed advisory->function map).

## Inputs available after merges
`osv-feed` (OSV index with affected ranges and, for Go, affected symbols: `osv_lookup.py`), `lang-servers` (`lsp_driver.py`, `treesitter_ast.py`, CodeQL lane), existing LLVM IR facts (`02-ir-facts`), Joern CPG (`02-code-property-graph`), `reachability.py` (CPG call-graph arbiter with witness), `02-sca-vulnerability-match`.

## Decisions (William)
- Use AST, IR, Joern, CodeQL or other language tooling, chosen per the DEPENDENCY's language and the application's language; be aware of differences by language.
- CodeQL is a first-class tool for languages that do not use LLVM: call-graph reachability (`Function.calls*` from entry points to the vulnerable function; entry points = `main`, exported handlers, framework routes) and taint tracking (`TaintTracking::Global` from `RemoteFlowSource` to the vulnerable API). Provide query templates per language under `data/codeql-reachability/<lang>/` with pinned pack versions; queries run only in the sandboxed codeql image and are fed advisory symbols as a parameter (generated by Python, never model text).
- Sources by ecosystem: C/C++ -> LLVM IR + Joern CPG (vendored dependency built with the target, when available); Go/Java/C#/JS/Python/Rust/PHP -> CodeQL call graph/taint first, then language-server call hierarchy, then tree-sitter call sites as a weaker fallback (never `reachable` from tree-sitter alone: name-based matches are `unknown` with a witness hint).
- Dependencies are vendored per version (artifact repository later); a missing dependency source degrades to `unknown` plus a gap. Advisory symbols come from the OSV index (Go now); when an advisory has no symbols, the result is `unknown` (package-level presence only) unless a reviewed advisory->function map exists.
- Model text never decides reachability. Persona judgement (if any) is only about whether a listed symbol is the vulnerable behaviour; Python assembles verdicts and witnesses.
