Reading guide

Every kind of content has one colour, one chip and one box. The chip text and the dashed border of the gap box carry the meaning too, so the report reads in greyscale.

Kinds of box

EVIDENCE#0F766E

REQUEST#334155
Application to model: the task, the role and model, and the tools the model may call.
MODEL#6D28D9
Model to application: a retrieve action or a final answer.
RESULT#0369A1
Rows the application retrieved for the model, with status and counts.
FEEDBACK#B45309
Application feedback: a denied request or a tool error, returned to the model as data.
CLAIM#B91C1C

COUNTER#1D4ED8
Blue counter-claim: an attempt to falsify a claim.

PROVENANCE#52525B

How to read a package

Each reviewed package has three parts. Evidence passed in is exactly what the application gave the model. Protocol interchange is the timeline of turns: the task and tools, what the model asked, what the application returned or denied, and the final answer, with token counts and the model used. Outcome is what reached the claim ledger. Long lists and results are cut and say so, with the SHA-256 of what was left out. Model output, target content and tool output are data and are never interpreted as instructions.
