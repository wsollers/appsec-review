Status vocabulary:
- **LIVE**: rendered into a dispatched model prompt and present in the dispatching worker's fingerprint.
- **LIVE-UNFINGERPRINTED**: rendered and dispatched, but absent from the worker's fingerprint, so a content change does not force a rerun.
- **LIVE-NOT-DISPATCHED**: passes test 1/2 (named by a template that renders) but no call site sends that template to a model. Added because test 1 alone would call these live.
- **DEAD**: no code path reads it into a prompt. "composition-only" means it is named by a template whose assembly fails, so it is never rendered.
- **MIRROR (OK)**: generated `prompt.md` that `catalog_personas.py check` keeps equal to its JSON; no worker reads it (`persona_registry.prompt_path` has no caller).
- **CONFIG**: read by code, never rendered (job templates, permission capabilities, container images).
