## What we learned about the design (feed into design-v3.md)

- The memory-safety lane is **query pack → traced DB → IR verification**; SVF is reachability
  enrichment, not the substrate. Cheaper and measurable.
- Three of four Notepad++ CVEs were static non-taint properties (wrong table constant, table
  shorter than state count, constant-length read). Taint tools are the wrong instrument for them.
- Game code will defeat name-based rules; detection has to be IR-level and the **allocator
  inventory** has to be automatic or explicitly model-driven (unmeasured — yquake2 experiment).
- IR-level rules are correct only after handling: call-site bounds, getter summaries, opaque-
  pointer field 0, inheritance GEPs, canonical class identity, iterators. See validation/eastl.md.
- Process: the file-download loop cost more than any single bug. Everything now goes through
  GitHub; the laptop tree is no longer canonical — the remote is.
