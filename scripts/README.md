# Scripts

- `render-report.sh` / `render-report.ps1` — render a finished review run to PDF or single-page
  HTML (`--format pdf|html` / `-Format pdf|html`). See
  [`docs/operations/report-rendering.md`](../docs/operations/report-rendering.md). Run with `--help`
  / `-Help` for the parameters. Output goes to `runs/reports/` by default (git ignored).
